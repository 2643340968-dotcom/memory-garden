# Memory Garden audio assets

Runtime audio is organized under this directory:

- `voice/`: optional interview, testimony, or memory clips associated with individual memory entries.
- `bgm/`: a future looping ambient track. No BGM is configured yet.
- `sfx/`: optional authored bloom/card cues. The current subtle cues are generated procedurally by `AudioManager`.

Do not label synthetic or unverified recordings as authentic historical testimony. Add source and rights information before replacing the current supplied clips or publishing new archival material.
